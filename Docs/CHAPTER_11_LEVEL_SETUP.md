# Chapter 11 — Echoes of the Fallen: Unreal Editor Integration Guide

Compile HunterGame and run `Tools/unreal/create_chapter11_level.py` from **Tools → Execute Python Script** to generate `/Game/Maps/Chapter11/L_CH11_EchoesOfTheFallen`. Build NavMesh before Play.

## Objectives
- Press E at each of three memory echoes (`ExpeditionMemoryRecovered`).
- Enter the Fallen Captain encounter radius and defeat the native multi-phase boss (`FallenCaptainDefeated`).
- Complete both objectives and reach the exit to save Chapter 11 and travel to Chapter 12.

Memory echoes are interactive greybox markers. The Captain uses the existing boss blockout, not a production character. Unique captain attacks, memory visuals, animation, VFX/audio, environment art and runtime testing remain outstanding.
