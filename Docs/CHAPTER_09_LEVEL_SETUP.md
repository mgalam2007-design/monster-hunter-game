# Chapter 09 — Whispers in the Dark: Unreal Editor Integration Guide

Compile HunterGame and run `Tools/unreal/create_chapter09_level.py` from **Tools → Execute Python Script** to generate `/Game/Maps/Chapter09/L_CH09_VanishedHunters`. Build NavMesh before Play.

## Objectives
- Reach the missing hunters' signal point (`MissingHunterSignalLocated`).
- Defeat four gate stalkers (`GateStalkerDefeated`).
- Press E at the expedition recorder (`ExpeditionRecorderRecovered`).
- Complete all three objectives and reach the exit to save Chapter 9 and travel to Chapter 10.

The recorder is currently an interactive greybox trigger rather than a finished pickup asset. Stalker models, signal effects, recorder art, environment art, animation, VFX/audio and runtime testing remain outstanding.
