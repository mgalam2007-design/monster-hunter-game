# Chapter 17 — The Last Sanctuary: Unreal Editor Integration Guide

Compile HunterGame and run `Tools/unreal/create_chapter17_level.py` from **Tools → Execute Python Script** to generate `/Game/Maps/Chapter17/L_CH17_LastSanctuary`. Build NavMesh before Play.

## Objectives
- Press E at five evacuation groups (`SanctuaryGroupEvacuated`).
- Defeat six sanctuary invaders (`SanctuaryInvaderDefeated`).
- Reach the exit after both objectives to save and travel to Chapter 18.

The evacuation points are interaction markers, not animated civilian escort AI. Civilian character assets, escort movement, siege scripting, animation, audio/VFX and runtime testing remain outstanding.
