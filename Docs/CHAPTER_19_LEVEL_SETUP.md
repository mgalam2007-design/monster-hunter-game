# Chapter 19 — Beyond the Gate: Unreal Editor Integration Guide

Compile HunterGame and run `Tools/unreal/create_chapter19_level.py` from **Tools → Execute Python Script** to generate `/Game/Maps/Chapter19/L_CH19_BeyondTheGate`. Build NavMesh before Play.

## Objectives
- Press E at all three origin gate seals (`OriginGateSealStabilized`).
- Defeat both origin sentinels (`OriginSentinelDefeated`).
- Reach the exit after both objectives to save and travel to Chapter 20.

The gate seals and sentinels are greybox interaction/native monster actors. Portal art, unique sentinel models/attacks, animation, VFX/audio and runtime testing remain outstanding.
