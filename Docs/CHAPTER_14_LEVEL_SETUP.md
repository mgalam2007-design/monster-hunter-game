# Chapter 14 — Broken Citadel: Unreal Editor Integration Guide

Compile HunterGame and run `Tools/unreal/create_chapter14_level.py` from **Tools → Execute Python Script** to generate `/Game/Maps/Chapter14/L_CH14_BrokenCitadel`. Build NavMesh before Play.

## Objectives
- Press E at all three command pylons (`CitadelPylonDestroyed`).
- Enter the commander encounter and defeat the native boss blockout (`CitadelCommanderDefeated`).
- Reach the exit after both objectives to save and travel to Chapter 15.

The commander currently uses the shared boss foundation, not a unique authored character. Citadel environment art, unique boss moves, animation, VFX/audio and runtime testing remain outstanding.
