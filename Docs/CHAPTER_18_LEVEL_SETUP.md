# Chapter 18 — Crown of Ruin: Unreal Editor Integration Guide

Compile HunterGame and run `Tools/unreal/create_chapter18_level.py` from **Tools → Execute Python Script** to generate `/Game/Maps/Chapter18/L_CH18_CrownOfRuin`. Build NavMesh before Play.

## Objectives
- Defeat four throne wardens (`ThroneWardenDefeated`).
- Press E at three command cores (`RuinCommandCoreDestroyed`).
- Reach the exit after both objectives to save and travel to Chapter 19.

The wardens use the current monster blockout and the cores are interaction markers. Unique warden art/attacks, ruined city environment art, animation, audio/VFX and runtime testing remain outstanding.
