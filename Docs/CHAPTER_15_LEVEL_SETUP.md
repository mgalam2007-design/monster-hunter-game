# Chapter 15 — Worlds Unsealed: Unreal Editor Integration Guide

Compile HunterGame and run `Tools/unreal/create_chapter15_level.py` from **Tools → Execute Python Script** to generate `/Game/Maps/Chapter15/L_CH15_WorldsUnsealed`. Build NavMesh before Play.

## Objectives
- Press E at all four breach anchors (`BreachAnchorStabilized`).
- Defeat both breach guardians (`BreachGuardianDefeated`).
- Reach the exit after both objectives to save and travel to Chapter 16.

The arena uses current monster blockouts and greybox interaction markers. Dimensional rift art, animated portals, guardian variants, VFX/audio and runtime testing remain outstanding.
